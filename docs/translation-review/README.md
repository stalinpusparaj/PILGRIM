# Translation review: Morning Manna (0.2.5 / 0.2.6)

One sheet per language. Each row is one piece of text in the game: the English, then our machine-written
translation. Please read it as a child aged 6-12 would hear it.

- Open the `.csv` file in Google Sheets or Excel.
- In **OK?** write `yes` if the line reads naturally for a child, or `no`.
- If `no`, write the better wording in the last column. Keep it short and warm (reading age 8).
- Keep anything in curly brackets exactly as it is, e.g. `{n}`, `{total}`, `{name}`: the game fills them in.
- Names of story characters (Christian, Hopeful, Faithful, Help...) should match the names already used in the game.

Send the filled sheet back and the corrections go into the next release.
